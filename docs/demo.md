# Демонстрационный стенд CampusFlow

**Эти учётные записи предназначены только для `compose.demo.yaml`.**
Расписание, группы и аудитории синтетические. Для стенда используется отдельный том PostgreSQL.

```sh
docker compose -f compose.demo.yaml up --build
```

При запуске через Compose напрямую откройте http://127.0.0.1:8767/. На Windows можно запустить run_dev.cmd из корня проекта. Он подхватит правки, оставит данные в томе и по умолчанию откроет стенд на порту 8768.

На первой странице демоверсии есть кнопки «Посмотреть расписание»,
«Забронировать аудиторию» и «Открыть диспетчерскую». Ниже можно открыть ручной вход.

| Роль | Логин | Пароль |
| --- | --- | --- |
| Студент | student | StudyFlow26! |
| Преподаватель | teacher | TeachFlow26! |
| Сотрудник деканата | dean | DeanFlow26! |
| Администратор | admin | AdminFlow26! |

После проверки логина и пароля CampusFlow покажет документы при первом входе и при смене редакции. Нужно отдельно подтвердить ознакомление с политикой и согласие. История и отзыв доступны в личном кабинете.
Для показа бронирования войдите преподавателем. Откройте «Бронирование», выберите
будний день в ближайшие четыре недели от первого запуска стенда, компьютерный класс
и 20 мест. Выберите вариант, удержите его и подтвердите бронь.

Остановка с сохранением данных:

```sh
docker compose -f compose.demo.yaml down
```

## Показ листа ожидания

Откройте два отдельных браузерных профиля. В первом войдите администратором, во втором преподавателем. В обоих выберите корпус 6, семинарскую аудиторию, 18 участников, завтрашнюю дату, своё время 19:00 и длительность 30 минут.

1. Администратор бронирует свободную аудиторию и подтверждает бронь.
2. Преподаватель выполняет тот же поиск и нажимает «Ждать освобождения».
3. Администратор открывает «Все брони» и отменяет свою демонстрационную бронь.
4. Преподаватель открывает «Мои брони» → «Лист ожидания». Когда работник фоновой обработки освободит слот, появляется «Открыть удержание». На подтверждение есть пять минут. Если очередь пуста, повторите поиск и проверьте дату, время и корпус.

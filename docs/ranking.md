# Модель переносов

OR-Tools CP-SAT строит допустимые варианты. Слот должен не пересекаться с другими
занятиями группы и преподавателя, бронями или удержаниями. Подбор учитывает
вместимость, тип, оборудование и доступность исходной аудитории. Закреплённые
и начавшиеся занятия оставляются на месте. Перед публикацией диспетчер принимает
предложение, после чего сервер повторно проверяет исходную выгрузку и занятость.

Модель LightGBM сортирует допустимые предложения по ожидаемому сокращению окон.
Она обучается на решениях диспетчеров. Признаки включают размер окна, день,
номер пары, смену корпуса, тип аудитории, размер группы, число групп и
преподавателей. Модель оценивает вероятность принятия и ожидаемое сокращение
окон. При нехватке решений предложения сортируются по рассчитанным минутам.

Для версии модели нужны как минимум 30 решений и оба исхода в ранней и поздней
частях истории. Последние 20% используются для сравнения. Для вероятности
показывается ошибка Brier относительно исторической доли принятия. Для минут
показывается MAE относительно простой эвристики. Затем модель обучается на
полной выборке. Версия, дата, объём выборки и метрики видны в диспетчерской.

На демостенде занятия и учебные решения синтетические. Реальных метрик пока нет.
Размер и точный курс группы зависят от данных каталога. Без размера оптимизатор
не делает перенос. Для групп менее пяти участников подробная аналитика скрыта.
Неизвестное время ходьбы помечается в интерфейсе. Для проверки коротких смен
корпуса CP-SAT использует консервативный порог в 20 минут.

Сетка по умолчанию служит для пилота. Перед запуском сверяйте её с расписанием
ИИМРТ и при необходимости задайте девять интервалов в CAMPUSFLOW_BELL.

### Разбор окон с Qwen

Запустите Ollama и проверьте наличие модели командой `ollama list`. При необходимости
установите её командой `ollama pull qwen2.5:7b`. В деморежиме Docker Desktop
CampusFlow обращается к Ollama на Windows по адресу `http://host.docker.internal:11434`.
Для сервера укажите локальный адрес в `CAMPUSFLOW_OLLAMA_URL` и локальный тег Qwen
в `CAMPUSFLOW_OLLAMA_MODEL`. В продакшене для подключения требуется указать адрес.

В «Окнах групп» откройте группу с известным размером от пяти человек, выберите
период с окнами и нажмите «Разобрать окна с ИИ». Ollama получает только числовые
сводки по дням недели и выбирает, что проверить. Все минуты и даты на экране
формируются из расчётов CampusFlow. CP-SAT по-прежнему строит варианты переноса, а их применение
подтверждает диспетчер.

Интеграция использует [структурированные ответы Ollama](https://docs.ollama.com/capabilities/structured-outputs).
